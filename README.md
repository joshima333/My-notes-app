# Note Vocali

App web (PWA) per registrare note vocali in italiano con trascrizione automatica.

- Trascrizione live gratuita (riconoscimento vocale del browser)
- Tipi di nota personalizzabili
- Audio salvato e riascoltabile
- Riassunto AI opzionale (chiave API Claude)
- Copia / condividi / scarica .txt
- Tutto salvato solo sul dispositivo

Uso: pubblicare con GitHub Pages (Settings → Pages → branch `master`), aprire il link con Chrome (Android) o Safari (iPhone) e "Aggiungi a schermata Home".
